# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be welcoming, patient and respectful. Assume good intent.
- Critique code and ideas, not people.
- No harassment, discrimination, sexualized language or imagery, personal attacks, or publishing others' private information.
- Maintainers may remove, edit or reject comments, commits, code, issues and other contributions that do not follow this code. They may also temporarily or permanently ban contributors for behaviour they consider inappropriate.

## Scope

This code applies in all project spaces: issues, pull requests, discussions and any channel that represents the project. It also applies when someone represents the project in public.

## Reporting

Report unacceptable behaviour privately to the maintainers through a [private security advisory](https://github.com/baryonlabs/macmini-ops/security/advisories/new) with the title "Code of Conduct". You can also contact an organization owner of [Baryon Labs](https://github.com/baryonlabs) directly. All reports are reviewed promptly and kept confidential.

Enforcement follows the Contributor Covenant [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines): correction, warning, temporary ban, then permanent ban.
